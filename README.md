# AI Administrator

A conversion-focused Uzbek-language landing page for an AI-assisted Telegram sales administrator. The product is designed to answer customer messages after business hours, share information from a business knowledge base, and capture leads for follow-up.

## Live demo

**[Open AI Administrator](https://akmalzokirjonov.github.io/ai-administrator/)**

## Highlights

- Clear before-and-after customer conversation comparison
- Responsive layout for desktop and mobile
- Accessible keyboard focus and reduced-motion support
- Progressive enhancement: core content remains visible without JavaScript
- Lightweight static deployment through GitHub Pages
- No framework or build step required

## Design approach

The page uses a dark navy palette to represent after-hours communication and amber as the single accent for successful responses. The central comparison shows the cost of silence next to an immediate automated reply, keeping the product value visible without unnecessary interface elements.

## Built with

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- GitHub Pages

## Run locally

```bash
git clone https://github.com/akmalzokirjonov/ai-administrator.git
cd ai-administrator
python -m http.server 8765
```

Then visit `http://localhost:8765`.
